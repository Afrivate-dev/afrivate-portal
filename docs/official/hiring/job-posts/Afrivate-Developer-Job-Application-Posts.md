# AfriVate Front-End Developer Application Post

## We’re Hiring: Front-End Developer

AfriVate Technologies Ltd is looking for a thoughtful and dependable Front-End Developer to build fast, accessible, and responsive digital products.

You will work primarily with React and TypeScript, turn product requirements into maintainable interfaces, integrate APIs, improve performance and usability, and collaborate through Git and GitHub.

**Location:** Remote  
**Employment type:** Full-time with a flexible work structure

### Core skills

- React, JavaScript (ES6+), TypeScript, HTML5, and modern CSS
- Responsive design and accessibility fundamentals
- React hooks, state management, forms, routing, and API integration
- Git and GitHub workflows, including branches, pull requests, and code review
- Debugging, testing, and clear technical communication

### Nice to have

- Vite, React Router, Tailwind CSS, and design systems
- TanStack Query, Zustand, Redux, or similar state tools
- Backend-as-a-service platforms such as Supabase, Firebase, or Appwrite
- Vitest/Jest, React Testing Library, and Playwright
- PWA development, CI/CD, Figma, performance, and web security

Practical ability matters. Strong early-career developers with credible projects are welcome to apply.

- Practical learning and direct exposure to product and engineering decisions

- Portfolio-strengthening work and cross-functional experience

# AfriVate Back-End Developer Application Post

## We’re Hiring: Back-End Developer

AfriVate Technologies Ltd is looking for a security-minded Back-End Developer to build reliable APIs, data models, integrations, and services for modern React applications.

Our recommended foundation is **TypeScript, Node.js using Express or Fastify, or NestJS, with PostgreSQL**. This gives the product team a shared language across frontend and backend with a strong relational data foundation.

**Location:** Remote  
**Employment type:** Full-time with a flexible work structure

### Core skills

- JavaScript/TypeScript and practical Node.js development
- Node.js using Express or Fastify, NestJS, or a comparable backend framework
- PostgreSQL, relational modelling, transactions, migrations, and indexing
- REST API design, validation, authentication, authorisation, and OWASP fundamentals
- Git/GitHub, pull requests, testing, debugging, and technical documentation

### Nice to have

- Prisma, Drizzle, or TypeORM
- Redis, queues, caching, background jobs, and webhooks
- Jest/Vitest, integration tests, and OpenAPI/Swagger
- Docker, Linux, CI/CD, monitoring, and cloud/serverless deployment
- Optional experience with Supabase, Firebase, Appwrite, or another backend-as-a-service platform
- Experience supporting React or React Native clients

You do not need experience with every nice-to-have technology. We value demonstrated ability, sound judgement, learning agility, security awareness, and ownership.
